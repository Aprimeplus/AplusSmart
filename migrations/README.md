# migrations/

สคริปต์เพิ่มคอลัมน์/ตารางในฐานข้อมูล PostgreSQL ที่เคยรันด้วยมือครั้งเดียวต่อฟีเจอร์ (ย้ายมาจากโฟลเดอร์หลักเพื่อไม่ให้รก)

- **โปรแกรมไม่เรียกใช้ไฟล์เหล่านี้** และไม่ถูกแพ็กเข้าตัวติดตั้ง — ฐานข้อมูลที่ใช้งานอยู่รันครบแล้ว
- เก็บไว้เป็นประวัติว่าฐานข้อมูลถูกเพิ่มอะไรมาบ้าง และใช้สร้างฐานข้อมูลใหม่ (เครื่องทดสอบ / ย้ายเซิร์ฟเวอร์) ต่อจากตารางพื้นฐานที่โปรแกรมสร้างตอนเปิดครั้งแรก (`_create_initial_db_tables` ใน `main_app.py`)
- ส่วนใหญ่รันซ้ำได้ปลอดภัย (ใช้ `IF NOT EXISTS`) แต่อ่านไฟล์ก่อนรันทุกครั้ง

## วิธีรัน

รันจาก **โฟลเดอร์หลักของโปรเจกต์** ด้วย `-m` (สคริปต์หลายไฟล์ import `main_app`):

```
python -m migrations.migrate_add_cost_benchmarks_history
```

ลำดับเวลาดูได้จาก `git log --follow migrations/<ไฟล์>`
