# tools/

สคริปต์งานครั้งเดียว/ตรวจสอบ ที่เคยใช้แก้ข้อมูลหรือนำเข้าข้อมูล (ย้ายมาจากโฟลเดอร์หลักเพื่อไม่ให้รก) — **โปรแกรมไม่เรียกใช้**

| กลุ่ม | ไฟล์ |
|---|---|
| นำเข้าข้อมูล | `import_*.py` (ลูกค้า, ซัพพลายเออร์, สินค้า, Markup Tiers, ประวัติยอดขาย) |
| ส่งออก | `export_supplier_master.py` |
| กู้/แก้ข้อมูล | `restore_order_no_from_export.py`, `revert_so_status.py` |
| ตรวจสอบ/ดีบัก | `check_dates.py`, `debug_logic.py`, `debug_payment.py` |

**ระวัง:** สคริปต์กู้/แก้ข้อมูลเขียนลงฐานข้อมูลจริงที่ใช้ร่วมกัน อ่านไฟล์และรันแบบ dry-run (ถ้ามี) ก่อนทุกครั้ง

รันจาก **โฟลเดอร์หลักของโปรเจกต์** ด้วย `-m`:

```
python -m tools.restore_order_no_from_export ไฟล์.xlsx --user KOY --bad "..."
```
